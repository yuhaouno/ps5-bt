# bt-l2cap

Allocation-free, safe `no_std` basic-header framing and received point-to-point
ACL recombination in caller storage. This is a framing foundation, not an
operational L2CAP channel implementation.

See [HCI-L2CAP.md](../../docs/HCI-L2CAP.md) for the API contract, ownership/epoch
requirements, bounds, missing policy layers, synthetic test provenance and
Bluetooth Core 6.0 section references.
