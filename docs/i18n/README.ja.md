# PS5 Bluetooth オーディオ（仮称）

PS5 の自作ソフトウェア環境向けに、Rust を中心とした低遅延・高音質で移植可能な Bluetooth オーディオスタックを開発します。内蔵 Bluetooth で一般的なヘッドホンを接続し、DualSense の無線動作を維持することが目標です。

**現在はフェーズ 0 の調査とリポジトリの基盤整備のみです。利用可能な音声ペイロードはなく、PS5・ファームウェア・ヘッドホンの互換性や遅延は未検証です。** C アダプターは未対応を返します。模擬テストは実機での動作保証ではありません。システム側との Bluetooth 通信の共有と SDK の起動処理には検討が必要です。

独立したプロジェクトであり、既存 C 実装の Rust 翻訳ではありません。有用なプラットフォーム固有の C コードは適切なライセンスと帰属表示の下で活用します。脱獄、権限昇格、DRM 回避、Sony のバイナリやファームウェアは提供しません。独自の成果物は GPL-3.0-or-later です。
