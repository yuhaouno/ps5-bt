# PS5 蓝牙音频（暂定标题）

以 Rust 为核心、面向 PS5 自制软件环境的蓝牙音频栈，目标是低延迟、高音质和可移植性。希望通过主机内置蓝牙连接普通耳机，同时保持 DualSense 无线操作。

**当前仅完成第 0 阶段的技术研究与仓库基础建设。尚无可安装的音频载荷，也未验证任何 PS5、固件、耳机或延迟指标。** 目前 C 适配层明确返回“不支持”；模拟测试不代表硬件兼容性。原生蓝牙流量归属与 SDK 启动行为仍需审查。

本项目独立开发，不是现有 C 项目的 Rust 翻译；会保留有价值的平台 C 代码，并尊重上游许可证与署名。项目不提供越狱、提权、DRM 绕过、索尼二进制文件或固件。原始贡献采用 GPL-3.0-or-later。

这是简要状态译文。[英文 README](../../README.md) 是权威版本；如翻译过时，以英文为准。构建、架构、研究与路线图请参阅英文文档。公开名称尚未确定，命名前需检查仓库与包名冲突。
