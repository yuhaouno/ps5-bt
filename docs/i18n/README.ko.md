# PS5 블루투스 오디오 — 임시 제목

PS5 홈브루 환경을 위한 Rust 중심의 블루투스 오디오 스택입니다. 낮은 지연 시간, 높은 음질과 이식성을 목표로 합니다. 본체 내장 블루투스로 일반 헤드폰을 연결하면서 DualSense 무선 작동을 유지하려고 합니다.

**현재는 0단계 조사와 저장소 기본 구조만 마련된 상태입니다. 사용할 수 있는 오디오 페이로드가 없으며 PS5, 펌웨어, 헤드폰 호환성이나 지연 시간도 검증되지 않았습니다.** C 어댑터는 명시적으로 지원하지 않음을 반환합니다. 모의 테스트는 PS5 실기 작동을 증명하지 않습니다. 시스템과의 블루투스 컨트롤러 공유 및 SDK 시작 동작은 추가 검토가 필요합니다.

기존 C 프로젝트를 Rust로 번역하는 프로젝트가 아닌 독립 프로젝트입니다. 유용한 플랫폼 C 코드는 라이선스와 기여자 표기를 지켜 재사용할 수 있습니다. 익스플로잇, 권한 상승, DRM 우회, Sony 바이너리나 펌웨어는 제공하지 않습니다. 자체 기여물은 GPL-3.0-or-later를 따릅니다.

이 문서는 간단한 상태 안내입니다. 번역이 오래된 경우에도 [영문 README](../../README.md)가 기준입니다. 빌드, 아키텍처, 조사와 로드맵은 영문 문서를 확인하세요. 최종 이름은 저장소 및 패키지 이름 충돌을 확인한 뒤 정합니다.
