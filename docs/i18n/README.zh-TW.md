# PS5 藍牙音訊（暫定標題）

以 Rust 為核心、面向 PS5 自製軟體環境的藍牙音訊堆疊，目標為低延遲、高音質與可攜性。希望透過主機內建藍牙連接一般耳機，同時維持 DualSense 無線操作。

**目前僅完成第 0 階段的技術研究與儲存庫基礎建置。尚無可安裝的音訊載荷，也未驗證任何 PS5、韌體、耳機或延遲數據。** C 適配層目前明確回傳「不支援」；模擬測試不代表硬體相容性。原生藍牙流量的歸屬與 SDK 啟動行為仍待審查。

本專案獨立開發，並非既有 C 專案的 Rust 翻譯；會保留有價值的平台 C 程式碼，尊重上游授權與署名。不提供越獄、權限提升、DRM 繞過、Sony 二進位檔或韌體。原始貢獻採 GPL-3.0-or-later。
